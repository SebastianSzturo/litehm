# Security policy

## Supported versions

Only the latest released version of LiteHM receives fixes.

## Reporting a vulnerability

Please report security issues, and any bug that can silently lose, corrupt, or
expose data, privately through
[GitHub private vulnerability reporting](https://github.com/SebastianSzturo/litehm/security/advisories/new).
Do not open a public issue.

Include the affected version, a minimal reproduction, and its impact. You should
receive a response within a few days. Once a fix is released, the advisory is
published with credit to the reporter unless you prefer otherwise.
